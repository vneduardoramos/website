# ViewNear — tiered image proposal (5 / 10 / 20)

A phased plan for the photography to acquire, building on the inventory in [`image-inventory-and-shotlist.md`](./image-inventory-and-shotlist.md). Each tier is cumulative (10 includes the 5; 20 includes the 10).

## The principle that makes this efficient

Almost the entire site pulls photography from **one shared stock pool** — `public/assets/images/photos/` (8 generic images: analytics, circuit, code, collaboration, dashboard, datacenter, network, team-meeting). That pool feeds home, **services**, solutions, **industries**, case studies, blog, news, partnership, platform, security, and contact. So a *small* set of authentic scene images, dropped into that pool, upgrades the **majority of the site at once** — including every Services surface. **Industries** is the one section that wants sector-specific imagery beyond the shared pool, so it gets its own track below.

> **Always do first (not counted in the 5/10/20):** real **team headshots** for everyone — one consistent session, square 1:1, neutral office/lounge background. Feeds About team cards, hero-diagram avatars, and blog author bylines. This is the single highest-trust fix and replaces the 4 generic seeded headshots. Count = your team size.

Legend: **AR** = aspect ratio to frame for (shoot a wider safe area so we can re-crop). **Source**: 🏢 in-house (your offices/team) · 🤝 client-site (needs client permission) · 🖼️ licensed stock (if a real shoot isn't feasible).

## Production notes (hand to whoever shoots)

- Shoot in real ViewNear environments (Austin / Monterrey); favor **candid working moments over posed stock**.
- Any visible screen must show **real Snowflake** (Snowsight dashboard, Cortex, IDE, governance/lineage) — never lorem-ipsum or a competitor UI.
- Consistent look per session: natural light, similar color temperature and depth of field; the brand reads cool/light ("Glacier"), so bright, airy, blue-friendly scenes fit best.
- For every hero/scene shot, capture a **wider safe-area frame** so we can re-crop to 16:9, 21:9, 4:5, and 1:1 without reshooting.
- Get a signed release for any identifiable person and any client-site shot.
